# Quantum Geometry Reproductions

Reproducible implementations of quantum-geometry research papers. Each study lives under `papers/<paper-slug>/`, with numerical tests, workflow adapters and documented physical assumptions.

The first study is Jia *et al.* (2026), *Nonlinear Magnetoelectric Edelstein Effect*. Its intrinsic and extrinsic response implementations explicitly distinguish verified limits from unresolved DC-response conventions.

See `papers/jia-2026-nonlin-magnetoelectric-edelstein/` for implementation, examples and reproducibility reports.
