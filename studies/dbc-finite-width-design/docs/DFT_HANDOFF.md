# DFT / Wannier 交接门槛

本研究阶段没有运行 DFT。下列内容定义进入材料验证所需的输入和否决条件。

1. **结构路径与占据。** 给出可实现控制量（位移、应变或场）和真实结构，不以模型 m 代替位移；核实整个比较区间绝缘、占据、SOC/spin 约定及能量参考。稳定性、双稳态与切换势垒属于独立材料证据。
2. **同规范算符。** 能带拟合通过不能替代响应验证。必须给同基底 H、完整位置/光学矩阵及必要导数的来源和哈希；HR+中心近似不自动等价于完整 Wannier 位置算符。用至少一个独立公式/DFT 光学参考核验目标张量及混合导数。
3. **坐标与单位。** 固定 Cartesian k、张量指标与结构域变换；冻结 eV、宽度类型、spin 重数、场 Fourier 约定、BZ 测度和 SI 前因子。二维先给 sheet response；有效厚度必须另行声明。
4. **临界类型。** 跟踪 Delta=Ec-Ev 的驻点与子空间，检查局部对称性、软三阶项、混合项以及 B_eff>0；记录 a'_c、K_c、偏斜 nu。二维假设不能直接套到一般三维色散。
5. **竞争与误差。** 识别其他光学阈值/驻点及对称等价谷。有符号合并，避免 patch 重叠。控制能量与光学矩阵元误差；使能差误差明显小于目标谱宽，再进行 k 网格、展宽、patch 与独立公式交叉检查。
6. **最终验证。** 在共同光子窗口内联合搜索真实控制参数和能量；分别报告峰高、积分谱重、固定频率响应与取消率。报告局部近似幅度误差、数值误差和优化不确定度，不以测试数量代替科学验收。

`closure.audit_material_contract` 只检查显式合同字段是否齐全，并拒绝 HR-only、宽度混用、未解析带簇等输入。其 accepted=True 绝不等于材料通过了上述实证检查。真实数据、POTCAR、论文 PDF/SM 和私有生产结果不进入此公开研究模块。
