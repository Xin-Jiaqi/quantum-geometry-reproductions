# Evidence provenance

`fresh_summary.json` is a compact extract of this run’s executed `scripts/reproduce_core.py --extended`; it records parameters, values, convergence and projector checks. The full JSON is regenerated by the same command and included in the downloadable research package. Timings may differ across machines.

`round4_parameter_validation.csv` and `round4_two_feature_validation.csv` are frozen previous-round results, not new optimization runs. Their raw_file column refers to the original round-4 archive, whose SHA256 is recorded in `study_manifest.json`; those paths are provenance labels, not files claimed to exist here. The current runner independently recalculates representative full-BZ values.

`legacy_test_audit.json` records this run’s execution of the prior source-reproduction and round1–4 tests. Inherited tests overlap; their counts must not be added as independent physics evidence. Tests in the current module run without these archives or private data.

No publisher PDF, private NLO source, DFT structure or material Hamiltonian is included.
