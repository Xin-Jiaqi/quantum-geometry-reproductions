## 2. 审查项 2+：AB 的 C₃v 张量约束（新发现）

固定堆垛 AB 为 P3m1（C₃v）。面内笛卡尔张量必须 M = γ·δ（M_xx=M_yy, M_xy=M_yx=0）。
本管线响应轴为斜基（b₁/b₂ 方向导数），经 Jacobian B⁻¹ 转到笛卡尔：

| AB 笛卡尔分量（1/(eV·T·Å²)） | 值 | C₃v 残差 |
|---|---|---|
| M_xx | +1.335e-9 | |M_xx−M_yy| = **4.94e-9** |
| M_yy | +6.272e-9 | |
| M_xy | +8.024e-9 | |M_xy| = **8.02e-9** |
| M_yx | +2.030e-9 | |M_yx| = **2.03e-9** |

**结论：AB 张量强违反 C₃v**（残差与分量同量级）。这不是斜基/Jacobian 误用
（已显式变换），而是数据/管线层面的对称性破坏。GLIDE（Aem2）张量同样非零
（见 Stage8m），其对角接近（|M_xx−M_yy|=4.7e-10）但反对称残差 |M_xy+M_yx|=5.1e-9。

## 4. 审查项 4：Wilson 相位数值精度（绝对误差预算）

对 AB/GLIDE 各 3 个低对称 k 点、双轴 dump 未除法 plaquette 相位：

| 量 | AB | GLIDE |
|---|---|---|
| 未除法相位 P(B=±0.25) | 4.3e-3 … 1.6e-2 | 1.4e-3 … 5.9e-2 |
| dP/2dB = Γ_k | 1e-7 … 2.6e-6 | 1e-8 … 1.1e-6 |
| |dP|/机器ε | 1.7e8 … 5.8e9 | 3.5e7 … 2.5e9 |

**结论：Wilson 相位本身非"微小相位"（10⁻³–10⁻² rad），B 差分可分辨（远超机器
精度），相位精度预算通过**。BZ 积分的 10⁻⁹ 量级来自 weight=ABZ/(2π)²/441 的
网格平均，不是微小相位差淹没在噪声中。

## 5. 审查项 5：SPN/MMN 数据对称性自洽（根因定位）

- SPN Hermiticity 偏差 1.3e-15（机器级）；S_z 对角 ≤ 0.9992（Pauli 归一正确）。
- **新增全网格镜像自洽检验（m_110，det=−1，AB 与 GLIDE 均有此操作）**：
  镜像等价 k 对（12 对）上 Tr(S_i²) 的最大差：
  **AB = 0.321，GLIDE = 1.025**（相对 96 带完备值 ≈ 0.3% / 1%）。
  Tr(S_i²) 是基不变标量，镜像下应严格相等——该残差直接度量**带基自旋矩阵在
  几何镜像下不自洽**，即 SPN 数据不严格携带堆垛对称性。
- glide sewing 的完全重构（U_g† H U_g − H 等）需要轨道级波函数（平面波/PAW 投影），
  提交的带基产物（EIG/SPN/MMN）不足以独立构造 U_g；本诊断以 spglib 空间群确认
  + 上述基不变标量残差作为数据层对称性检验（审查评论允许的最低可执行版本）。

**根因判定**：引擎（合成 glide 中点 frame+mmn 双零、合成高对称张量零）与
网格/排序/归一化（坐标查表、链式、σ/2）均干净；破坏定位在 **VASP 输出数据
（SPN/MMN）在 ISYM=0 后处理与滑移几何下的数值对称性不严格**，量级 0.3–1%，
足以把对称性强制为零的张量分量抬升到与物理分量同量级（10⁻⁹）。

- 结果（AB，5 低对称 k × 双轴）：**1 个 k 点（0.44,0.12）rel < 0.5（0.037/0.47），

- 记录为**部分交叉验证 + 明确的规范限制**；公式（含 U†∂U 项）写入
