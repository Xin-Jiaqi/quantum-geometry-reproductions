# 绘图约定

目的：先展示双层 KM 的结构、控制参数和响应，再展示 MoSSe 的结构、层距机制、冻结杂化与门控；夜间辅助测试单独成图。Python/matplotlib，178 mm 双栏，PNG 320 dpi、PDF/SVG 可编辑文字。借鉴文献的论证顺序，不复制文献图像或数据。

图 1：KM 模型示意 + t_perp 扫描 + U 扫描 + 同层正负动量区域贡献的变化。固定 m=45 meV 等既有参数，所有20个该设置计算点保留；共同起点用于两条路径。动量正负分组随参数变化，不能解释为固定的两个原子轨道通道。示意有限晶格不代表计算使用有限样品。
图 2：MoSSe S/S 原子坐标的侧向投影 + 7个原有层距点 + 两个端点的带组贡献。原子坐标取原结构，增加d仅刚性分开两层；未作弛豫。较深36条、顶部12条占据带分组与原分解一致，柱形数据使用完整k点集合平均。不存在通过拟合调整分组。
图 3：44态/112态材料模型缩放整个d+p层间块 + A层响应随Fz变化 + A/B总响应随Fz变化。两材料模型均原样绘制；其幅值与临界缩放不同，不混称定量一致。图 2/3所有C单位1e-9 (nm V T)^-1。α=0不是新的孤立层自洽DFT。
图 S1：单侧Se扰动结构示意 + 独立DFT的两畴曲线。Se位移箭头放大，仅作扰动检验，非实际基底。
图 S2：同一50nm高度、50nm宽矩形探针的两个横向位置，按已计算自旋密度的理想边缘磁场；两图纵轴不同并明确标注aT。非实测、非噪声或仪器性能模拟。
图 S3：原/半探测场总系数曲线 + 两个层距端点不同k网格的下层系数。误差条不适用；两点连线不是物理插值曲线，仅同设置端点对照。
