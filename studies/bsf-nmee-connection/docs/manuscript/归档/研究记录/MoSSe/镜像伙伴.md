# MoSSe S/S 镜像伙伴的静态层自旋

2026-11-05。A 为 BiDB 7269；B 为其水平镜像伙伴。相对下层 Mo，A 的上层 Mo 面内配准为 (1/3, 2/3)，B 为 (2/3, 1/3)。两者下层朝向均为 Se–Mo–S，实验室轴、探测 Eₓ 与自旋 Bz 同号。自由中性板层、固定离子、相同层距。将两张板层的界面中面统一移到真空胞 z=1/2，以避免把原点/网格的区别当成畴信号。B 的自旋与电荷从原子起算，不镜像拷贝 A 的电子态。A 也独立重算。预言为 C下(B,F)=−C上(A,−F)、C净(B,F)=−C净(A,−F)。零点附近的小值不单独用来判正负，需两侧异号。

已从独立原子电荷分别启动 A/B 的 0、±0.25、±0.50 V/nm 成对计算。PBE/PAW、450 eV、SOC、6×6×1，全局 BEXT=+0.016 eV，面内探测场 Eₓ=±0.004 V/Å。正负指 VASP 的电子受力场约定。参照原 7269 输入模板，仅复用静态设置、赝势及 k 点。层积分在界面与真空中点等分边界平面。日本原始数据：/work/sunq/xjq/mosse-ss-domains-20261105；工作量、作业号及实际节点保存在 jobs.json 和各点结果中。

## 独立 DFT 结果

单位为 $10^{-9}(\mathrm{nm\,V\,T})^{-1}$。每组的 F 取 VASP 的垂直电子受力方向，表中 B 偏场为 A 的相反数。

两堆垛都保持下层负、上层正。零场下，A 的下层幅度较大，B 的上层幅度较大。用 0.18 与 0.32 V/nm 的两个明显异号端点插值，A 的补偿位置为 +0.2441 V/nm；B 用 −0.32 与 −0.18 V/nm 插值得 −0.2440 V/nm。另用最近邻点插值分别为 +0.2444、−0.2442 V/nm。正文只取约 ±0.24 V/nm。相反偏场下净值之和在全部五组成对数据中绝对值小于 0.001（表中单位）。层值近似按镜像交换再取反，因两个自洽态和微小密度差独立求取，不赋予末位差异物理意义。

所有板层保持绝缘，零面内场种子的间接隙范围 0.814–0.837 eV。A 重算与早期固定层距 7269 的净值和趋势一致。早期 9×9 互易法校验过原堆垛两端的净值符号，本轮两堆垛用同一 6×6 网格的独立正负面内电场自洽密度给出补偿场，数值不是收敛到末位的器件临界栅压。

结论限于上下对称环境、固定离子、弱探测、单一配准在扫场中保持的 MoSSe 双层。两种自由板层的机械稳定性由镜像关系继承；本次未模拟滑移写入、基底、器件栅极、畴混合或磁信号探测极限。补偿位置的正负可作为理想结构的畴标记；单凭整片信号不能反演上下层的具体自旋。
