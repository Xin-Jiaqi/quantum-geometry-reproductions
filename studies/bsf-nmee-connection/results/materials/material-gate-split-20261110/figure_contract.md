# Figure contract

Claim: In the existing self-consistent states MoSSe has strongly asymmetric fractional layer control; its lower layer is not markedly less sensitive fractionally than InSe's lower layer.
Evidence: (a) signed gate slopes in common units; (b) fractional decrease of each layer's own response amplitude over the same -0.10 to +0.10 V/nm interval. This does not establish an energy/matrix cancellation mechanism.
Archetype: quantitative two-panel grid, second panel carries the comparison.
Backend: saved Python preference; matplotlib only.
Export: 183 x 78 mm, editable SVG/PDF, 600 dpi PNG; layer_changes.csv plus all_diagnostics.csv. Deterministic numerical results, no statistical error bars.
Selection: main figure uses the largest available band windows (112/160) and smallest probe (0.0000625 eV), anchored correspondence. All 54 diagnostic rows retained in all_diagnostics.csv; plots summarize four layer values, not independent samples. Energy/matrix attribution is rejected as unconverged and is not plotted as a mechanism result.
